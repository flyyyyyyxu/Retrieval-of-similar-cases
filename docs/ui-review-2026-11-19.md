## 本轮修复

| 问题 | 修复 |
| --- | --- |
| 未截断的短摘要也有“展开” | 按实际渲染高度判断；在切换摘要、刷新案例和窗口变宽/窄时更新 |
| 没有摘要且文书读取失败，只剩“查看原文” | 列表增加重试；原文分栏重试期间立即显示加载状态 |
| 报告编辑器脚本加载失败后无法在原位置恢复 | 增加“重试编辑器”，重建编辑视图并保留内存中的报告草稿；编辑器就绪前禁用格式工具 |
| 从独立报告/文书页面返回到不存在的当前检索 | 无当前结果时转到“新建检索”；有结果时保留返回检索 |
| JSON 元信息导出被笼统标成“导出选中案例” | 改为“导出案例信息（JSON）”，与 Word/PDF 报告导出区分 |
| 案情和年份同时无效，后续校验抢走案情焦点 | 首个错误立即返回，先定位问题输入 |
| 页面分别使用绿蓝渐变、亮蓝、浅绿文字和不同灰度 | 新增统一主题与 design.md；保留现有结构与业务流程 |

静态检查：模板中 49 个不同的 `data-action` 值均有处理分支；未发现空 `href="#"` 或 `javascript:` 占位链接。这是入口覆盖检查，不能替代完整行为测试。
